# 시험 데이터 지우기 (관리자 계정만 남기기)

여러 번 시험해 본 뒤 실제 서비스를 처음 상태로 되돌릴 때 씁니다.
`reset-keep-admin.sql` 한 파일을 Supabase에서 실행하면 됩니다.

## 남는 것과 지워지는 것

| 남는 것 | 지워지는 것 |
| --- | --- |
| 관리자 계정 (카카오 로그인 그대로) | 아이 전부와 아이 기록 (출석, 나무·물방울·포인트, 미션 기록, 고민, 댓글·좋아요, 심방, 배지, 달란트) |
| 기본 설정 (물방울 규칙, 가입 QR 코드와 켜짐·꺼짐) | 관리자가 아닌 선생님 계정 (다시 초대해야 함) |
| 마이그레이션 기록 | 반, 미션(고정·순환·기간), 주별 말씀 |
| | 소식 글, 공지, 예배 순서 |
| | 올린 사진 전부, 활동 기록 |

- **되돌릴 수 없습니다.** 지금 쓰는 Supabase 무료 요금제에는 날짜를 골라 되살리는 기능이 없습니다.
- 인쇄해 둔 **가입 QR은 그대로 쓸 수 있습니다** (설정에 있는 가입 코드는 지우지 않음).
- 아이 QR 카드는 아이와 함께 지워지므로, 예전에 인쇄한 아이 카드는 쓸 수 없게 됩니다.
- 반과 미션도 지워지므로, 지운 뒤에는 반 편성과 미션 계획(고정 미션 4개 만들기)부터 다시 합니다.
- 번호는 처음부터 다시 매기지 않습니다. 예전에 시험하던 휴대폰이 새로 가입한 다른 아이로 들어가는 일을 막기 위해서입니다. 시험하던 휴대폰은 로그인 화면으로 돌아갑니다.

## 스스로 멈추는 경우 (아무것도 지우지 않음)

- 로그인할 수 있는 관리자 계정(카카오가 연결됐거나 쓰지 않은 초대 코드가 있는 관리자)이 하나도 없을 때
- 지우는 목록에 없는 새 표에 데이터가 남아 있을 때 (앱에 표가 새로 생기면 `reset-keep-admin.sql`의 목록에 넣어야 함)

## 실행하는 방법 (Supabase 관리 화면)

1. https://supabase.com 에 로그인하고 꿈의숲 프로젝트를 엽니다.
2. 왼쪽 메뉴에서 **SQL Editor**를 엽니다.
3. `reset-keep-admin.sql`의 내용을 전부 복사해 붙여 넣습니다.
4. **Run**을 누릅니다.
5. 아래에 남은 관리자 계정 한 줄(이름, admin, kakao_linked = true)이 보이면 끝입니다.
   오류 문구가 나오면 아무것도 지워지지 않은 것입니다. 문구를 그대로 알려 주세요.

## 확인

`test/reset-keep-admin.test.ts`가 모든 표에 데이터를 넣은 시험 데이터베이스에서 이 파일을 실행해,
관리자·설정만 남는지, 두 번 실행해도 되는지, 위의 두 경우에 멈추는지 확인합니다.
