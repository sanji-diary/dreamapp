# 달걀 홀인원

꿈의숲교회 소년부 부활절 행사에서 혼자 즐기는 휴대폰 미니게임입니다. 화면을 당겼다 놓아 달걀을 발사합니다. 꽃밭에서는 첫 골을 넣으면 다음 바구니가 더 멀고 높은 곳에 나타납니다. 담 너머 코스에서는 쿠션을 타거나 담을 넘겨 던지는 등 어떤 경로든 목표 바구니에 들어가면 득점합니다. 여기서도 첫 골 뒤에 거리가 바뀝니다. 두 코스에 각각 두 골을 넣고 마지막으로 좌우로 움직이는 수레에 한 골을 넣으면 완주합니다.

빗나간 달걀도 바닥이나 옆 바구니에서 통통 튑니다. 시도 횟수와 제한 시간은 없습니다. 넣은 골은 같은 판에 유지되며, 연속 두 번 빗나가면 바구니 입구가 조금 넓어집니다. 힌트를 보고 각도와 힘을 직접 조절해 다시 던질 수 있습니다.

## 실행

Node.js 22.13 이상에서 압축을 풀고 이 폴더의 `게임 실행.cmd`를 더블클릭합니다. 터미널에서는 아래 한 줄로 실행할 수 있습니다.

```sh
node server.mjs
```

PC에서는 `http://localhost:4186`을 엽니다. 같은 와이파이의 휴대폰은 터미널에 표시된 Phone 주소를 엽니다. 모바일 앱과 다른 네트워크에서 함께 쓸 때는 게임 서버의 HTTPS 주소를 사용합니다. 로컬 실행 기록은 `.data/egg.sqlite`에 저장됩니다.

## 테스트와 빌드

```sh
node --test
node build.mjs
node --check dist/server/index.js
```

별도 npm 패키지 설치 없이 실행됩니다. 빌드는 웹 에셋과 공통 판정 코드를 Worker 형식으로 묶습니다. 일반 Node 서버와 호스팅용 Worker는 같은 코스와 완주 판정 코드를 사용합니다. Worker 배포에는 D1 바인딩 `DB`와 `drizzle/` 마이그레이션이 필요합니다.

## 수정할 곳

| 변경 | 파일 |

## 소년부 앱(꿈의숲키우기)에 연결된 방식

앱이 이 게임을 직접 제공합니다. 따로 올린 게임 서버가 없어도 학생은 앱 안에서 게임을 할 수 있습니다.

- 관리자가 미션 계획에서 "게임" 미션을 만들고 〈달걀 홀인원〉을 고르면 아이의 미션 목록에 나옵니다.
- 게임 화면: 앱 주소 뒤의 `/minigames/egg-hole-in-one/index.html`. 이 폴더의 `public/` 파일을 앱이 그대로 보냅니다. 복사본이 없으므로 여기서 고치면 앱에도 반영됩니다.
- 판 기록과 완주 검증: 앱의 `src/lib/kid/egg-game.ts`와 데이터베이스 표 `egg_rounds`. 완주 판정은 이 폴더의 `rounds.mjs`(`isCompleteRound`)와 `public/physics.mjs`를 그대로 불러 씁니다.
- 보상: 미션에 정한 물방울과 포인트가 한 번만 들어갑니다. 주간 한도와 "한 주에 한 번"도 다른 미션과 같습니다(앱의 `src/lib/kid/hosted-game.ts`).
- 게임 화면은 서버를 상대 주소(`api/rounds`)로 부릅니다. 그래서 이 폴더를 혼자 실행할 때와 앱 안에서 열 때 모두 같은 파일로 동작합니다.
- 앱 쪽 검사: 저장소 맨 위에서 `npx vitest run test/egg-game.test.ts`.
